## 新增/修正的参考判断

- 新增的独立父项目只有OPP五模块项目，来源是原09-01～09-05的完整合并组织，不是新增采集事实。五个模块各自的时间/目的仍在选项中。
- 第3条证件核验归候考子步骤，签到/抽签同属候考；不重复计证件核验。两场面试合并/分列的等价表达继续允许。
- 第4/5条正文均可读，分别169/145字。冻结源文快照、当前只读SQLite、旧模型输入逐字一致、内容指纹一致；附件内容未读取/未验证。修正原“正文不可用”错误，不能从资料属性为空推断正文状态。
- 六条海外项目的学习计划/学分认定提交与学院权限说明归校内申请要求，跟进审核归步骤；原文明确独立的学院申请审核仍保留。
- 第12条外方1—2工作日邮件确认是材料受理步骤，保留时限，不误当外方录取结果。
- 第11条历史签约/启动为背景，减免为条件式机会，回校取毕业证/毕业审核为培养要求；本轮不虚构新的毕业办理入口。
- 第15条考核形式归项目要求，证书/成绩/推荐信/报告归成果属性；明确的考核结果发布仍独立，保留相对4周约束。
- 第13条历史申请/审核/公示/外申/项目/出国流程均保留，两个冲突日期均存且已过期；住宿两种报价保留为备选费用，不计两个住宿事项。
- 层级映射不改变原文事实：源文、旧编号、主体目的、时间节点和证据全部可追溯；主通知类别与事项类型分开，不用费用/审核等事项类型充当通知分类。
