## 待人工确认的口径

- 类别按通知主要用途，不由背景介绍的竞赛、奖学金或讲座关键词直接决定。
- 重要性按资格后果、机会价值或资金/培养安排判断，不依据临近或过期；理由不足时允许未知，有争议时列多个可接受值供审查。
- 行动包括原文明示的条件式异议/报名，不表示当前用户有资格或必须办理；历史报名描述不能当成新的行动。
- 报名截止只收学生申请相关目标，排除学院行政审核、公示与异议期限。建议第11条包含学生申请、必要缴费、外方网申、独立奖学金申请；最后两个同日但目标不同。
- 时区、年份或数字时刻缺失时保持未知；英国时间不自动换成UTC偏移。只有“13.00”时按现有契约不归一化成“13:00”。滑铁卢通知两处校内日期冲突，应保留冲突和未知，不私自选择一个。
- 第3条复试两场可合并或分别表达，但进场窗口不得冒充面试时间；第10条建议学科表8场本科说明会加1场PGT，首场不重复计数。
- 时间评分只比较归一化点集合，不能证明活动标签和报名主体语义正确，仍需审查本表备注。只有明确认可的等价方案才放入 accepted_deadline_points/accepted_event_points，不全局混同 null 与空数组。
- 本组无真实个人偏好，相关性必须未知；模型可用性与“执行失败”不计成正确预测。全部工具只允许get_notice_detail，默认未加载正文时一次读取具有合理需求。
